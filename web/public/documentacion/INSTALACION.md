# INSTALACION - Instrucciones de instalación del sistema Medusse IoT

## Requisitos previos

- Docker & Docker Compose
- Node.js 18+
- Python 3.9+

## Pasos rápidos

1. Clonar el repositorio
2. Entrar en la carpeta `api` y ejecutar `npm install`
3. Ejecutar `docker-compose up -d` desde la raíz para levantar InfluxDB, Grafana, Mosquitto y MySQL
4. Ejecutar `npm start` en `api` para iniciar la API
